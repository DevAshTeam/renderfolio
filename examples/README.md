# Examples

The live demo of Renderfolio, deployed to GitHub Pages:

https://DevAshTeam.github.io/renderfolio/

- `john_doe_portfolio.md` — the **source of truth**. Edit this, never the HTML.
- `html/` — generated files, committed so Pages can deploy them with no build step.`index.html` is a copy of the main theme; each `<theme>.html` is one render;`resume.pdf` is the `--pdf` output. and a 404.html.
